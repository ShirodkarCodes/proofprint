ProofPrint
API

Generate media that can prove where it came from.

Every asset is generated through a multi-provider Genblaze pipeline, sealed with a SHA-256 provenance manifest embedded inside the file, and written to Backblaze B2 under Object Lock. The proof travels with the image.

Verify a file

Drop any image. ProofPrint extracts the embedded manifest, recomputes its canonical hash, and re-hashes the bytes against the immutable record in Backblaze B2. Change a single pixel and the check fails.

Every sealed asset, read straight from the B2 ledger.
